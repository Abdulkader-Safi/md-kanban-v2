# Connect your own folder

Click "Connect folder" in the sidebar and pick a folder for your tasks, for example `tasks/` inside a repo.

- Every `.md` file in the folder is a card, up to four folders deep.
- Each first-level subfolder is a work folder, listed in the sidebar.
- mdk writes nothing in your folder except card files. Its settings live in the OS config folder.

> [!warning] Pick a tasks folder, not a repo root
> A repo root would turn the README and every other markdown file into a card.
