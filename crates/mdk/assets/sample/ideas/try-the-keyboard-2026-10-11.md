# Try the keyboard

- [ ] Cmd+K (Ctrl+K) opens the command palette: find a card, create one, or run a command
- [ ] Arrow keys walk the cards, Enter opens one
- [ ] Turn on "Vim keys in editor" in the sidebar and edit a card with `dd`, `cw` and friends
- [ ] Save a filter as a view and click its chip to bring it back
