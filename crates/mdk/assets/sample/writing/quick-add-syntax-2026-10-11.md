# Quick-add syntax

Press `N` on the board and type a whole card in one line:

```
Fix login p1 #backend @safi due:friday
```

| You type | It sets |
| --- | --- |
| `p1` to `p4`, or `critical`, `high`, `medium`, `low` | Priority |
| `#backend` | A label |
| `@safi` | The assignee |
| `due:today`, `due:tomorrow`, `due:friday`, `due:2026-12-01` | The due date |
